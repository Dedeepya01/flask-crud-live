# Flask CRUD REST API

A simple CRUD (Create, Read, Update, Delete) REST API built using **Python Flask**, **SQLAlchemy**, **PostgreSQL**, and **Docker**.

This project demonstrates how to build and run a RESTful API with a PostgreSQL database using Docker containers.

## 🚀 Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- PostgreSQL
- Docker
- REST API



## ⚙️ Features
- Create a new record
- Get all records
- Update a record
- Delete a record
- Dockerized application
- Web application
